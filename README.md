# Toaba for Unity

The Unity SDK for [Toaba](https://toaba.io), the PaaS for live games: player accounts and content
delivery, from Unity 6.

It's at an early stage and not ready for use yet.

## Install

In Unity, open **Window → Package Manager**, select **+ → Install package from git URL**, and enter:

```text
https://github.com/toaba-io/toaba-unity.git
```
